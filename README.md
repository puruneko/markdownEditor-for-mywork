# MD AST Editor

Markdownベースのタスク管理エディタ。カレンダー・ガントチャート・かんばん・ダッシュボードの複数ビューで可視化できます。

Obsidianプラグインとして動作し、マークダウン形式で書かれたタスク・プロジェクトを効率的に管理できます。

## 主な機能

- **マークダウンベースのタスク管理**: チェックボックスと階層構造でタスクを整理
- **複数のビュー**: 
  - Calendar View: 日付ベースの可視化
  - Gantt View: スケジュール管理と依存関係の追跡
  - Kanban View: ステータスベースの作業管理
  - Dashboard View: 複合的なメトリクス表示
- **メタ情報システム**: 期限、優先度、タグ、繰り返し、条件、目的など多様な情報を付与
- **時間管理**: 計画期間（plan）、実施日時（schedule）、期限（due）の3層モデル
- **エディタ拡張**: メタ情報の自動装飾、サジェスト、ドラッグ&ドロップ対応
- **複数ファイル対応**: Vault全体またはフォルダ単位での索引化

## 対象ユーザー

- マークダウン形式でタスク・プロジェクトを管理したいユーザー
- Obsidianでタスク可視化を必要とするユーザー
- 複雑なスケジュールと依存関係を扱うユーザー

## 基本的な使い方

### インストール

Obsidianの「コミュニティプラグイン」から「MD AST Editor」をインストール、または以下のステップでセットアップします：

```bash
npm install
npm run build
# 出力ファイルを Obsidian プラグインディレクトリにコピー
```

### タスク記法の基本

```markdown
# プロジェクト名

## サブプロジェクト

- [ ] 未着手のタスク
  - @schedule: 2026-10-15T10:00/11:00
  - @due: 2026-10-20
  - @priority: 1
  
- [>] 進行中のタスク
  - @plan: 2026-10-01/2026-10-31
  
- [x] 完了したタスク
```

### ビューの開く

Obsidian コマンドパレット（Ctrl+P / Cmd+P）で以下を検索：

- `Calendar View を開く`
- `Gantt View を開く`
- `Kanban View を開く`
- `Dashboard View を開く`

### エディタコマンド

- `カーソル位置のタスクのメタ情報を折りたたむ/展開`: カーソル位置のメタ情報を折りたたみ/展開
- `すべてのメタ情報を折りたたむ`: ドキュメント全体のメタ情報を折りたたみ
- `すべてのメタ情報を展開`: ドキュメント全体のメタ情報を展開
- `メタ行を推奨位置へ整形（現在のファイル）`: メタ情報をタスク直下の推奨位置に自動配置

## セットアップ方法

### 前提条件

- Node.js 18以上
- npm 9以上
- Obsidian 1.0.0以上

### 開発環境のセットアップ

```bash
# 依存パッケージをインストール
npm install

# 開発サーバー起動（動作確認用）
npm run dev

# ビルド（開発用）
npm run build:dev

# ビルド（本番用）
npm run build

# esbuild でプラグイン向けにビルド
npm run build:app
```

### Obsidianプラグインとして組み込む

```bash
# プラグインファイルを Obsidian プラグインディレクトリにコピー
# ~/.obsidian/plugins/md-ast-editor/ に以下をコピー：
# - main.js
# - manifest.json
# - styles.css
```

## テスト方法

```bash
# ユニットテスト（vitest）
npm run test:unit

# E2Eテスト（Playwright）
npm run test:e2e

# Obsidian E2Eテスト（WebdriverIO）
npm run test:obs:e2e

# すべてのテストを実行
npm run test
```

## 設定

Obsidian 設定パネル（プラグイン設定 > MD AST Editor）で以下を調整できます：

- **リボンアイコン表示**: 左サイドバーのアイコン表示/非表示
- **タスクハイライト**: エディタ内のメタ情報の自動装飾
- **日付ピッカーの分刻み**: 時刻入力時の分の粒度（1/5/10/15/20/30分）
- **よく使うメタ情報名**: サジェスト表示時の優先順位（日付系の後に表示）
- **メタ情報の別名**: 特殊メタキーの日本語エイリアス設定
- **索引スコープ**: 索引化対象（Vault全体またはフォルダ指定）
- **デバウンス時間**: ファイル変更検知の遅延（ミリ秒）
- **スクロールオフセット**: カーソル移動時のスクロール位置
