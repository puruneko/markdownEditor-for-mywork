# メタ情報（メタキー）完全ガイド

Markdownのタスク行に付与される `@キー: 値` 形式のメタ情報について詳しく解説します。

## メタ情報の基本

メタ情報はタスク行の直下に記述されるリスト項目として表現されます。

```markdown
- [x] 契約書レビュー
  - @schedule: 2026-10-15T14:00/15:00
  - @due: 2026-10-20
  - @priority: 1
  - @tags: 事務, 法務
  - @memo: 営業部長に確認を取る
```

タスク上の引用ブロック（`>`）は自動的に `@memo` として扱われます：

```markdown
- [ ] 営業会議
  > 参加者: 営業部全員、事業企画部長
```

## メタキー一覧

### 時間関連

#### @schedule（実施日時）

実際に手を動かす具体的な日時を指定します。複数の時間範囲を指定できます。

```markdown
- [ ] 朝礼
  - @schedule: 2026-10-15T09:00/09:30
```

**書式**: `YYYY-MM-DDT時:分/時:分` または `YYYY-MM-DD/YYYY-MM-DD`

**特徴**:
- 開始時刻と終了時刻を指定
- 仮置き可能（`@schedule?: ...`）- 日程が未確定の場合

#### @plan（計画期間）

その期間の中で実施するというバッファを含む大まかな枠を指定します。

```markdown
- [ ] Q4プロジェクト
  - @plan: 2026-10-01/2026-12-31
```

**書式**: `YYYY-MM-DD/YYYY-MM-DD`

**特徴**:
- 期間で指定（時刻は含まない）
- スケジュールの大枠を示す

#### @due（期限）

最終的に完了すべき期限を指定します。

```markdown
- [ ] 報告書提出
  - @due: 2026-10-31
```

**書式**: `YYYY-MM-DD` または `YYYY-MM-DDTHH:mm`

**特徴**:
- 期限超過はビュー上で強調表示される可能性あり

#### @repeat（繰り返し）

定期的に繰り返すタスクの規則を指定します。

```markdown
- [ ] 日報提出
  - @schedule: 2026-10-15T17:00/17:10
  - @repeat: FREQ=DAILY; BYDAY=MO-FR
```

**書式**: iCalendarの RRULE 形式

**よく使う例**:
- `FREQ=DAILY; BYDAY=MO-FR` - 平日毎日
- `FREQ=WEEKLY; BYDAY=MO` - 毎週月曜
- `FREQ=MONTHLY; BYMONTHDAY=15` - 毎月15日

### タスク情報

#### @priority（優先度）

タスクの優先度を数値で指定します（1=最高、数値が大きいほど低い）。

```markdown
- [ ] 緊急対応
  - @priority: 1

- [ ] 将来の改善
  - @priority: 5
```

**書式**: 整数（推奨: 1-5）

#### @tags（タグ）

タスクを分類するためのタグ（複数指定可）。

```markdown
- [ ] 営業資料作成
  - @tags: 営業, マーケティング, 資料作成
```

**書式**: カンマ区切り（例: `営業, マーケティング`）

#### @dependsOn（依存関係）

このタスクが依存する他のタスクを指定。Gantt View で依存関係として表示されます。

```markdown
- [ ] 仕様書承認
  - @schedule: 2026-10-10T10:00/11:00

- [ ] 開発開始
  - @dependsOn: (同じファイル内のタスク行参照)
  - @schedule: 2026-10-15T10:00/17:00
```

**使用場面**: プロジェクト内のタスク依存チェーンを表現

#### @condition（完了イメージ）

タスクが「完了」とみなされる条件を記述します。

```markdown
- [ ] 顧客ヒアリング
  - @condition: 要件定義書が顧客に承認される
```

**書式**: 自由形式（テキスト）

#### @purpose（目的）

タスクを実施する理由や目的を記述します。

```markdown
- [ ] ユーザーテスト実施
  - @purpose: ユーザー体験の改善点を特定し、次版開発の優先度を決定する
```

**書式**: 自由形式（テキスト）

#### @savepoint（セーブポイント）

長期プロジェクト内の中間チェックポイントを指定します。

```markdown
- [ ] フェーズ3開発
  - @savepoint: ベータ版リリース / 初期ユーザー100名獲得
```

**書式**: 自由形式（テキスト）

#### @special_note（特記事項）

特別な注記や外部システムの参照情報。

```markdown
- [ ] バグ修正
  - @special_note: GitHub #1234 参照
```

**書式**: 自由形式（テキスト）

### その他

#### @memo（メモ）

タスクに対する補足情報。エディタでは任意の子要素（引用ブロック `>`）から自動抽出されます。

```markdown
- [ ] 打ち合わせ
  > 営業部との事業企画について
  > 参加者: 部長、課長、AI担当者
```

**書式**: 引用ブロック（`>`）またはメタ行（`- @memo: ...`）

## 日本語別名

設定で英字キーの日本語別名を定義できます。

**組み込み別名**（設定で変更可能）:

| 英字キー | 日本語別名 |
|---------|----------|
| plan | 想定期間 |
| schedule | 実施日時 |
| due | 期限 |
| condition | 完了イメージ |
| purpose | 目的 |
| savepoint | セーブポイント |
| special_note | 特記事項 |

例：

```markdown
- [ ] 営業報告
  - @実施日時: 2026-10-15T16:00/16:30
  - @期限: 2026-10-20
```

## メタ情報の入力補助

エディタで `@` を入力するとサジェストが表示されます。

**サジェスト順**:
1. 時間関連キー（schedule, plan, due）
2. 設定で指定した「よく使うメタ情報名」
3. その他のキー（priority, tags, など）
