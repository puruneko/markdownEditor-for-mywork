# タスク記法ガイド

MD AST EditorはMarkdownファイル内のタスク記法で、複雑なプロジェクト・スケジュール管理を実現します。

## タスクの基本構文

タスクはMarkdownの標準チェックボックスリスト形式で記述されます：

```markdown
- [ステータス] タスク名
  - メタ情報（オプション）
```

## タスクステータス

チェックボックス内の文字でタスクの状態を表現します：

| 文字 | ステータス | 用途 | 例 |
|------|-----------|------|-----|
| `?` | 計画中 (planning) | まだ開始予定が決まっていないタスク | `- [?] システム設計 ` |
| ` `（空白） | 未着手 (ready) | 開始準備ができている状態 | `- [ ] 開発開始` |
| `>` | 進行中 (in_progress) | 現在作業中のタスク | `- [>] ドキュメント作成` |
| `!` | 待機中 (waiting) | 外部の完了を待っている状態 | `- [!] クライアント承認待ち` |
| `/` | 保留中 (deferred) | 一時的に中断しているタスク | `- [/] 後期フェーズ対応` |
| `x` | 完了 (done) | タスク完了 | `- [x] テスト完了` |
| `-` | 中止 (cancelled) | キャンセルされたタスク | `- [-] 廃止機能` |

## メタ情報について

タスクの直下にメタ情報を付与できます。詳細は [META_KEY_GUIDE.md](./META_KEY_GUIDE.md) を参照してください。

### 基本例

```markdown
# Q4プロジェクト

## フェーズ1：計画

- [ ] システム設計
  - @schedule: 2026-10-15T10:00/12:00
  - @due: 2026-10-20
  - @priority: 1

- [>] ドキュメント作成
  - @schedule: 2026-10-15T14:00/17:00
  - @plan: 2026-10-15/2026-10-31
  - @tags: ドキュメント, マニュアル

- [!] クライアント承認
  - @due: 2026-10-25
  - @condition: クライアント署名を受取

## フェーズ2：開発

- [?] 実装開始
  - @dependsOn: クライアント承認
  - @priority: 2

- [x] テスト
  - @schedule: 2026-10-01T09:00/2026-10-05T18:00
```

## ステータス遷移

タスクは以下のように遷移することを想定しています：

```
計画中 (?) → 未着手 ([]) → 進行中 ([>]) → 完了 ([x])
              ↓
            待機中 ([!]) → 進行中 ([>]) → 完了 ([x])
            
            保留中 ([/]) → 進行中 ([>]) → 完了 ([x])

            中止 ([-])
```

## 階層構造

タスクはネストされた階層構造を持つことができます：

```markdown
- [ ] 親タスク
  - @schedule: 2026-10-15T10:00/11:00
  - [ ] 子タスク1
  - [ ] 子タスク2
    - [ ] 孫タスク
```

ビューでは以下のようにサポートされます：
- **Calendar View** - 時間ベースでのスケジュール表示
- **Gantt View** - 階層構造と依存関係の可視化
- **Kanban View** - ステータス列の表示

## メモ・補足情報

タスク直下の引用ブロック（`>`）は自動的にメモとして処理されます：

```markdown
- [ ] 会議実施
  > 参加者: 営業部長、事業企画部
  > 場所: 会議室A
  > 持参物: 提案資料
```

## よくある使いパターン

### シンプルなTODOリスト

```markdown
# 今週のTODO

- [ ] メール返信
- [ ] レポート作成
- [ ] 部長との打ち合わせ
```

### スケジュール付きプロジェクト

```markdown
# 製品ローンチ

- [ ] キックオフ
  - @schedule: 2026-10-08T14:00/15:00
  
- [ ] 実装フェーズ
  - @plan: 2026-10-10/2026-10-24
  - [ ] バックエンド実装
  - [ ] フロントエンド実装
  - [ ] テスト
  
- [ ] リリース
  - @schedule: 2026-10-31T15:00/16:00
  - @due: 2026-10-31
```

### 複雑なプロジェクト管理

```markdown
# システム更新プロジェクト

- [ ] 要件定義
  - @schedule: 2026-10-01T10:00/2026-10-05T18:00
  - @priority: 1

- [ ] 設計フェーズ
  - @dependsOn: 要件定義完了
  - [ ] アーキテクチャ設計
  - [ ] DB設計
    - @condition: 全テーブル定義書が承認される

- [ ] 開発フェーズ
  - @dependsOn: 設計完了
  - @plan: 2026-10-15/2026-11-10
  - [>] バックエンド実装
    - @schedule: 2026-10-15T09:00/2026-10-30T18:00
  - [ ] フロントエンド実装
  - [ ] テスト
```

## エディタでのサポート機能

- **メタ情報のサジェスト**: `@` を入力するとメタキー候補が表示されます
- **メタ情報の折りたたみ**: `Ctrl+Shift+M` でカーソル位置のメタ情報を折りたたみ
- **構文検証**: メタ情報の形式を自動チェック
- **自動装飾**: メタ情報をハイライト表示

詳細は README.md の「エディタコマンド」セクションを参照してください。
