# ビュー機能ガイド

MD AST EditorはMarkdownファイルを複数の角度から可視化・操作するビューシステムを提供します。

## ビューの種類

### Calendar View（カレンダービュー）

日付を基準にタスクを表示します。

**使用場面**:
- 日次・週次・月次のスケジュール確認
- 期限管理
- 時間単位の予定立て

**表示内容**:
- `@schedule` メタキーで指定した開始時刻と期間
- `@plan` で指定した計画期間
- `@due` で指定した期限
- タスクのステータス（未着手・進行中・完了など）

**操作**:
- タスク行をドラッグしてカレンダーの時間グリッドへドロップ：時刻・期間を設定
- 日付をクリック：該当ファイルのカーソルが移動

### Gantt View（ガントチャートビュー）

プロジェクト全体のスケジュール構成と依存関係を見やすく表示します。

**使用場面**:
- プロジェクトのスケジュール管理
- 複数タスクの並列実行管理
- マイルストーンと期限の確認
- サブタスク構造の可視化

**表示内容**:
- 階層的なタスク（親・子関係）
- 期間（`@plan` / `@schedule` / `@due`）
- 依存関係（`@dependsOn`）
- 優先度（`@priority`）
- 完了度（ステータス）

**設定**:
- サブタスク表示: 設定で親タスク内にサブタスクを展開表示するかを選択

### Kanban View（かんばんビュー）

タスクをステータス列で整理します。

**使用場面**:
- 日次作業の進捗管理
- タスクの流れを段階的に追跡
- チームワークでのステータス管理

**表示内容**:
- ステータス列（計画中・未着手・進行中・待ち・保留・中止・完了）
- 各タスクのメタ情報（優先度・期限・タグ等）
- タスクのフィルタリング（タグ・優先度別）

**操作**:
- カード間でドラッグ&ドロップ：ステータスを変更
- 列をクリック：ステータスごとの詳細表示

### Dashboard View（ダッシュボード）

プロジェクト全体の統計・メトリクスを表示します。

**表示内容**:
- タスク数（ステータス別の進捗率）
- 優先度分布
- 期限超過タスク
- タグ別の統計

**使用場面**:
- 全体的な進捗把握
- ボトルネック特定
- 期限管理

### AST View（開発者向け）

Markdown解析結果のAST（抽象構文木）をJSON形式で表示します。メタ情報の確認やバグ報告時に便利です。

### Parse Debug View（開発者向け）

パーサーの動作を確認するビューです。
