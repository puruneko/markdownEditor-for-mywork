# メタ情報の折りたたみを「2行以上のメタ項目ごと」に作り直す

## 背景
- リポジトリ: `markdownEditor-for-mywork`。
- 要望原文（「折りたfみ」は「折りたたみ」の誤字）:
  > メタ情報の折りたたfみ機能
  > 　@rv: １行メタ情報は対象外。２行以上になっているものに対して、メタ情報名の行の名前の後ろに小さく折り畳み／展開のボタンを設置。折り畳みの時にメタ情報名の行はそのままで、２行目以降を折りたたんで非表示にする。このとき、後続の行番号がズレないよう、消すのではなくあくまで見えないようにすること。
- 前回（phase017）の実装は「タスク行の下のメタ行のまとまり全体」を1行のウィジェット「▸ メタ情報 (N件)」に置き換えるもので、単位も見た目も @rv と異なる。
- 採用した解釈:
  - 「2行以上になっているメタ情報」= メタ行（`- @key` / `- @key: value`）の直後に、そのメタ行より深いインデントの行（子行・続きの行）が1行以上あるもの。子行の無いメタ行（1行メタ）にはボタンを付けない。
  - 「メタ情報名の行の名前の後ろ」= メタ行の `@key` の直後。
  - 「折り畳み時はメタ情報名の行はそのまま、2行目以降を非表示」= メタ行自体は表示したまま、子行だけを見えなくする。
  - 「行番号がズレないよう、消すのではなく見えないように」= Markdown の本文は一切変更しない（表示上の装飾だけで隠す）。隠した後の行も、エディタの行番号は元の番号のまま表示される（隠した行の番号が飛ぶだけで、後続の番号は詰まらない）。

## 目的
複数行のメタ項目ごとに、メタ行の名前の後ろの小さなボタンで子行を折りたたみ・展開できるようにする。

## 現状
- `src/editor/meta-fold.ts`（191 行）
  - `META_LINE_RE = /^(\s*- )@([\p{L}\p{N}_]+)(\?)?(?::(.*))?$/u`、`TASK_LINE_RE`、`getIndent`。
  - `findMetaBlocks(lines)`: タスク行ごとに直下のメタ行のまとまり（子孫行を含む）を `MetaBlock { taskLine, firstLine, lastLine, metaCount }` として返す純粋関数。
  - `metaFoldField`: 折りたたみ中の「タスク行の行頭位置」の配列。`toggleMetaFold` / `foldAllMeta` / `unfoldAllMeta` の StateEffect。カーソルが範囲に入ると自動展開。
  - `buildDecorations`: 折りたたみ中は `Decoration.replace({ widget: FoldedWidget, block: true })` でまとまり全体を置換、それ以外はまとまりの先頭に `ToggleWidget`（▾）。
  - `toggleMetaFoldAtCursor(view)`: カーソルのあるタスク行のまとまりを切り替える。
- `src/plugin.ts:16,159-179`: 拡張の登録と、コマンド「カーソル位置のメタを折りたたみ/展開」「すべて折りたたみ」「すべて展開」。
- スタイル: `styles/metatag-raw.css:87-100` 付近の `.metatag-fold-widget` / `.metatag-fold-toggle`（`styles.css` はビルド生成物なので直接編集しない）。
- メタ行は `src/editor/metatag-decoration.ts` で装飾（チップ表示など）される。テスト: `src/editor/meta-fold.test.ts`。

## 実装内容
1. 検出単位をメタ項目ごとにする（`meta-fold.ts`）
   - `findMetaBlocks` を、メタ行ごとの `MetaItemBlock { metaLine, keyEnd, firstChildLine, lastChildLine }` を返す関数（例 `findFoldableMetaItems(lines)`）に置き換える。対象はタスク配下（タスク行より深いインデント）のメタ行のうち、直後にそのメタ行より深いインデントの行が1行以上続くもの。子行の範囲は「メタ行より深いインデントが続く間」（空行で終わる）。`keyEnd` はその行の中で `@key`（`?` があれば含む）の直後の文字位置。
2. 状態: `metaFoldField` が保持する値を「折りたたみ中のメタ行の行頭位置」にする。自動展開（カーソルが子行の範囲に入ったら展開）、文書変更時の位置の追従は現状の仕組みを流用する。`foldAllMeta` / `unfoldAllMeta` はすべてのメタ項目に対して動くようにする。
3. 表示（`buildDecorations`）
   - ボタン: 対象のメタ行の `keyEnd` に `Decoration.widget({ widget, side: 1 })` で小さなボタンを置く（展開中 `▾`、折りたたみ中 `▸`）。クリックでそのメタ項目を切り替える。
   - 折りたたみ: メタ行の行末から最後の子行の行末までを `Decoration.replace({})`（`block` なし・ウィジェットなし）で隠す。メタ行はそのまま表示され、子行だけが見えなくなる。本文は変更しない。
   - `FoldedWidget`（「▸ メタ情報 (N件)」）とタスク行単位のトグルは削除する。
   - `metatag-decoration.ts` の装飾がメタ行の `@key` 部分を置換していて、`keyEnd` のボタンが表示されない場合は、その置換範囲の直後にボタンを置く。
4. コマンド: `toggleMetaFoldAtCursor` は「カーソルのある行がメタ行ならそのメタ項目、子行ならその親メタ項目」を切り替えるように変える。コマンド名の文言は必要に応じて合わせる。
5. スタイル（`styles/metatag-raw.css`）: ボタンは本文より小さい文字（例 0.8em）・控えめな色（`var(--text-muted)`）・クリック可能なカーソルにする。不要になった `.metatag-fold-widget` は削除する。

## 完了条件
- 子行を持つメタ行の `@key` の直後に小さなボタンが表示され、子行の無いメタ行には表示されない。
- ボタンを押すと、メタ行は表示されたまま子行だけが見えなくなり、もう一度押すと元に戻る。
- 折りたたみ・展開で Markdown 本文が変わらない（undo 履歴に残らない）。
- 折りたたみ中も、後続行の行番号は元の番号のまま表示される。
- 折りたたんだ範囲にカーソルが入ると自動で展開される。
- コマンド「すべて折りたたみ」「すべて展開」が全メタ項目に対して動く。
