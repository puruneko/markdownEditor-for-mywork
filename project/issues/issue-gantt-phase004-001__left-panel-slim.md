# [gantt] 左パネルのスリム化（インデント幅・パネル幅の prop 化とリサイズ）

## 1. 課題と方針  — 人間が読む

### このissueで解決すること
オーナーの実運用フィードバック: 「左パネル（ツリー）のデフォルトインデントが深すぎ、パネル幅も広すぎて、タイムライン（本来見たいもの）の表示領域が狭い」。個人のタスク管理ではタスク名は短く階層は浅いため、現行デフォルトは過剰。

### 方針
ハードコードされているインデント幅・パネル幅を prop 化し、デフォルト値を縮小。さらにパネル境界をドラッグでリサイズできるようにする。**依存なし・即着手可**（phase004-000 Step 0）。

### 仕様
1. 新 prop（GanttChart のトップレベル）:
   - `indentWidth?: number` — 階層 1 段あたりの px。**新デフォルトは現行値の約半分**（現行値を特定した上で、10〜14px 目安）。
   - `panelWidth?: number` — 左パネル初期幅 px。新デフォルトは現行より 2〜3 割縮小。
2. パネル境界にドラッグハンドルを追加し、リサイズ可能にする。リサイズ結果はコンポーネント内部状態（`$state`）で保持。**永続化はライブラリの責務にしない**（どこに保存するかはホストごとに違う。`onPanelResize?: (width: number) => void` コールバックだけ用意し、ホストが保存したければ拾えるようにする — 汎用性維持の原則）。
3. 既存利用者（本体）が prop 未指定でも壊れないこと（すべてオプショナル＋デフォルト値）。

### 実装の要点・つまずき
- リサイズは pointerdown → window の pointermove/up で実装（マウスがハンドル外へ出ても追従させるため）。同種の実装がライブラリ内の DnD 処理にあれば流用。
- 最小幅（例 80px）・最大幅（例 タイムラインを 200px 以上残す）のクランプを入れないと、ユーザーがパネルを潰して戻せなくなる。
